\sectiontitle{Scenario content}
The source scenario contains 73 named parameters and 163 explicit target-path changes. It is applied after the model is first materialised from the reference parameter set.

\sectiontitle{Internal validity}
The card is generated from the scenario registry, so each listed change has a source path and value. Runtime comparison evidence is stored in the run JSON rather than repeated in full here.

\sectiontitle{Face validity}
This sample card is mainly a readability check for the new grammar. It should be reviewed against the clinical or policy intention of the scenario before being treated as signed-off.
